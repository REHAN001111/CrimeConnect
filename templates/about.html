About CrimeConnect

Online Crime Reporting and Complaint Management System developed as a college Information Technology Lab (ITL) full-stack software engineering project.

Project Objective & Scope

Traditional manual complaint logging often suffers from physical queues, lack of verifiable acknowledgments, and opaque status updates for citizens. CrimeConnect addresses these issues by offering a digital portal where citizens can submit structured incident reports, immediately obtain an algorithmic reference code, and track the progress of their complaints transparently.

The platform features a distinct, protected administrative dashboard that empowers authorized operators to triage incoming reports, request additional details, record public updates, and document internal investigative notes.

Technology Stack

Backend Architecture Python 3, Flask 3.x, Flask-Login, Flask-WTF, WTForms
Database & Storage SQLite 3 with SQLAlchemy ORM, isolated file storage
Frontend Interface HTML5 semantic structure, CSS3 responsive design, JavaScript, Chart.js, Font Awesome
Testing Framework Pytest unit & integration test suite

Security & Defensive Engineering

  • Cryptographic Password Storage: Passwords are hashed using Werkzeug's secure hashing functions, preventing exposure in case of data breaches.
  • Role-Based Access Control (RBAC): Role fields are strictly server-managed. The registration route hardcodes the citizen role, disallowing privilege escalation. Admin routes are guarded by a custom @admin_required decorator.
  • CSRF Protection: All state-changing POST forms utilize unique CSRF tokens verified via Flask-WTF.
  • Path Traversal Defense: Uploaded evidence files are renamed to UUID identifiers and stored in a non-public folder; file access is authenticated and checked against complaint ownership.
  • SQL Injection Prevention: Parameterized queries mediated by SQLAlchemy ORM protect database queries from injection attacks.
  • Two-Factor Tracking Authorization: Public status queries require both the unique reference number and complainant email to prevent unauthorized data exposure.

Academic Demonstration Disclaimer

CrimeConnect is designed strictly as an educational software engineering prototype for ITL coursework. It does not possess legal standing and is not affiliated with any actual emergency service or law enforcement agency.
